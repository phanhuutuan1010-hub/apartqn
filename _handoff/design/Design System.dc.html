Rules Container: content max 1200px, centred, side padding 16 / 24 / 32. Zero horizontal scroll at every width — carousels scroll inside their own track only. Layout switches on measured page width (no device sniffing), so the same file renders correctly at 360, 390, 768, 1024, 1280. Tap targets ≥ 44px (buttons, chips, pills, nav rows, footer links). Inputs 16px to avoid iOS zoom. Body 16/1.6. Headings: line-height ≥ 1.15 + 0.08em top padding so stacked Vietnamese diacritics (ề ể ố ộ ữ) never clip. Key phrases joined with no-break spaces: dài hạn · trung tâm · Quy Nhơn. ContactBox: sticky right column ≥ 1024; below that a sticky bottom bar (2 locale contacts + red “Hẹn xem căn”) with safe-area inset.
